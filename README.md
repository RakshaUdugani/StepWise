# StepWise 🚶‍♀️

> A minimalist Android fitness app for tracking daily activity, understanding health metrics, and building better workout habits.

## 📱 Overview

StepWise is an Android fitness tracking application built with **Kotlin and Jetpack Compose**.

The app combines real-time step tracking, weekly activity insights, BMI calculation, custom workouts, and fitness resources in a simple, soft pastel interface.

## ✨ Features

- 🚶 **Real-time Step Tracking** — Track daily steps and monitor activity.
- 📊 **Weekly Activity Overview** — Visualize your activity across the week.
- ❤️ **Health Connect Integration** — Access step and health-related data.
- ⚖️ **BMI Calculator** — Calculate and understand your Body Mass Index.
- 🏋️ **Custom Workouts** — Create and manage personalized workouts.
- 📰 **Fitness Articles** — Access fitness and wellness resources.
- 🎨 **Minimal UI** — Clean, soft pastel interface designed for easy navigation.

## 🛠️ Tech Stack

- **Kotlin**
- **Jetpack Compose**
- **Material 3**
- **Android Health Connect**
- **Gradle**

## 🚀 Getting Started

### Prerequisites

- Android Studio
- Android device or emulator
- Android SDK
